# Database Schema Documentation

## Overview

The AI SQL Assistant uses PostgreSQL with two schemas:

| Schema | Purpose |
|--------|---------|
| `metadata_schema` | Application metadata: dataset catalog, query history |
| `user_data` | Dynamically created user dataset tables |

---

## Metadata Schema

### `metadata_schema.datasets`

Catalog of all uploaded datasets.

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | UUID | PK, NOT NULL | Unique dataset identifier |
| `name` | VARCHAR(255) | NOT NULL | Human-readable dataset name |
| `original_filename` | VARCHAR(500) | NOT NULL | Original uploaded filename |
| `table_name` | VARCHAR(255) | UNIQUE, NOT NULL | Dynamic table name in user_data schema |
| `column_schema` | JSONB | NOT NULL | Array of column definitions |
| `row_count` | INTEGER | NOT NULL | Number of rows in the dataset |
| `file_size_bytes` | BIGINT | NOT NULL | Original file size |
| `status` | VARCHAR(50) | NOT NULL, DEFAULT 'processing' | 'processing'\|'ready'\|'error' |
| `error_message` | TEXT | NULLABLE | Error details if status='error' |
| `created_at` | TIMESTAMP | NOT NULL, DEFAULT NOW() | Upload timestamp |
| `updated_at` | TIMESTAMP | NOT NULL, DEFAULT NOW() | Last update timestamp |

**`column_schema` JSONB structure:**
```json
[
  {
    "name": "order_id",
    "db_type": "TEXT",
    "nullable": false,
    "sample_values": ["ORD001", "ORD002", "ORD003"]
  },
  {
    "name": "total_amount",
    "db_type": "DOUBLE PRECISION",
    "nullable": false,
    "sample_values": ["2599.98", "1497.50", "450.00"]
  }
]
```

---

### `metadata_schema.query_history`

All queries executed against datasets.

| Column | Type | Constraints | Description |
|--------|------|-------------|-------------|
| `id` | UUID | PK, NOT NULL | Unique query identifier |
| `dataset_id` | UUID | FK → datasets.id (SET NULL on delete) | Associated dataset |
| `natural_language_query` | TEXT | NOT NULL | Original user question |
| `generated_sql` | TEXT | NOT NULL | SQL generated by LLM |
| `validated_sql` | TEXT | NULLABLE | SQL after validation/cleanup |
| `result_summary` | JSONB | NULLABLE | Metadata about results |
| `status` | VARCHAR(50) | NOT NULL | 'success'\|'error'\|'rejected' |
| `error_message` | TEXT | NULLABLE | Error details |
| `execution_time_ms` | INTEGER | NULLABLE | Query execution duration |
| `created_at` | TIMESTAMP | NOT NULL, DEFAULT NOW() | Query timestamp |

**`result_summary` JSONB structure:**
```json
{
  "row_count": 10,
  "columns": ["order_id", "customer_name", "total_amount"],
  "execution_time_ms": 45
}
```

*Note: Full result data is NOT stored to keep the metadata table lean. Results are re-queried on demand for exports.*

## User Data Schema

### Dynamic Tables: `user_data.ds_{uuid_short}`

One table per uploaded dataset. Created dynamically based on detected schema.

**Naming convention**: `ds_` + first 8 chars of dataset UUID (e.g., `ds_550e8400`)

**Example DDL** (for a sales CSV upload):
```sql
CREATE TABLE IF NOT EXISTS "user_data"."ds_550e8400" (
  _row_id SERIAL PRIMARY KEY,
  "order_id" TEXT,
  "customer_name" TEXT,
  "product" TEXT,
  "category" VARCHAR(255),
  "quantity" BIGINT,
  "unit_price" DOUBLE PRECISION,
  "total_amount" DOUBLE PRECISION,
  "order_date" TIMESTAMP,
  "region" VARCHAR(255),
  "salesperson" TEXT
);
```

**Notes:**
- `_row_id` is always added as an auto-increment primary key
- All user column names are double-quoted to handle reserved keywords
- Column names are sanitized: spaces → underscores, special chars removed
- Types are conservatively mapped (TEXT preferred over VARCHAR for safety)

## PostgreSQL Roles

```sql
-- Application role: full access to metadata schema
CREATE ROLE aisql_app WITH LOGIN;
GRANT ALL ON SCHEMA metadata_schema TO aisql_app;
GRANT ALL ON SCHEMA user_data TO aisql_app;

-- Query execution role: read-only on user data only
CREATE ROLE aisql_query WITH LOGIN;
GRANT USAGE ON SCHEMA user_data TO aisql_query;
-- SELECT granted per-table when dataset is created:
-- GRANT SELECT ON "user_data"."ds_xxxxxxxx" TO aisql_query;
```

## Type Mapping

| pandas dtype | PostgreSQL type |
|-------------|----------------|
| `int64` / `int32` | `BIGINT` |
| `float64` / `float32` | `DOUBLE PRECISION` |
| `bool` | `BOOLEAN` |
| `datetime64[ns]` | `TIMESTAMP` |
| `object` (avg len < 255) | `VARCHAR(500)` |
| `object` (avg len ≥ 255) | `TEXT` |
| `category` | `VARCHAR(255)` |
| Anything else | `TEXT` |

---

## Indexes

The following indexes are created automatically:
```sql
-- For fast dataset lookups by table_name
CREATE INDEX idx_datasets_table_name ON metadata_schema.datasets(table_name);

-- For query history filtering
CREATE INDEX idx_query_history_dataset_id ON metadata_schema.query_history(dataset_id);
CREATE INDEX idx_query_history_created_at ON metadata_schema.query_history(created_at DESC);
```
